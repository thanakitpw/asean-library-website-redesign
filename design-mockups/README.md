# โครงการห้องสมุดอาเซียน — แบบดีไซน์หน้าแรก 6 แนวทาง

Mockup HTML สำหรับให้ลูกค้าเลือกแนวทาง ก่อนพัฒนาจริงด้วย Next.js + ฐานข้อมูล

> **ลูกค้าเลือกแบบที่ 3 Learning Space (9 ต.ค. 2569)** — ต่อยอดเป็นหน้าย่อยครบทั้งเว็บแล้วที่ `learning/`

## Learning Space ทั้งเว็บ (`learning/`)
| ไฟล์ | หน้า |
|---|---|
| `learning/index.html` | หน้าแรก (แบบที่ 3 + ลิงก์จริงไปทุกหน้า) |
| `learning/about.html` | เกี่ยวกับโครงการ: ที่มา วัตถุประสงค์ สิ่งที่อยู่ในห้องสมุด เส้นทางโครงการ กลุ่มเป้าหมาย |
| `learning/network.html` | เครือข่าย 77 แห่ง: ค้นหา กรองตามภาค เรียงตามปีที่เปิด |
| `learning/news.html` / `news-detail.html` | รายการข่าว (กรองหมวด/ค้นหา) และหน้าอ่านข่าว (แห่งที่ 76) |

| `learning/gallery.html` | คลังภาพแบบอัลบั้ม + lightbox |
| `learning/contact.html` | ติดต่อ: ช่องทางติดต่อ ฟอร์ม (ยังไม่ส่งจริง) คำถามที่พบบ่อย |

**ห้ามแก้ไฟล์ใน `learning/` ตรง ๆ** — ต้นฉบับอยู่ที่ `../mockup-src/learning/` (header/footer/ไอคอนรวมไว้ที่ `build.py`, เนื้อหาแต่ละหน้าอยู่ใน `pages/`, ข้อมูลห้องสมุดอยู่ใน `data/libraries.json`) แก้แล้วรัน `python3 mockup-src/learning/build.py`

### ข้อมูลเครือข่ายห้องสมุด (ต้องให้ลูกค้ายืนยัน)
- ดึงจาก API เว็บเดิม (`/web/news/get-province-by-zone`) แล้วแก้จังหวัดที่ระบบเดิมบันทึกผิด ตามหัวข้อข่าวพิธีเปิด (เช่น แห่งที่ 74–76 ระบบเดิมผูกไว้กับนครพนม แต่ข่าวระบุชุมพร ยะลา นราธิวาส) และเพิ่มแห่งที่ 72 บึงกาฬ ที่ขาดไป
- ผล: 76 แห่ง ใน 76 จังหวัด ไม่ซ้ำกัน จังหวัดที่ยังไม่มีคือ **ปัตตานี** จึงใส่เป็นแห่งที่ 77 ไว้ก่อน (ยังไม่มีชื่อโรงเรียน)
- 15 แห่งไม่มีเลขลำดับในข้อมูลเดิม จึงแสดงเป็นปีที่เปิดแทน
- เนื้อหาที่เป็นตัวอย่าง (ไม่ได้มาจากเว็บเดิม): เนื้อหาบทความ ARF, บทความหมวดเกี่ยวกับอาเซียน/ภาคีภายนอก/ก้าวไปกับอาเซียน, คำถามที่พบบ่อย

## วิธีดู
- เปิด `index.html` — มีแท็บสลับ 3 แบบ และปุ่มสลับ Desktop / Tablet / Mobile
- หรือเปิดแต่ละไฟล์ตรง ๆ:
  - `design-1-official.html` — **ทางการ (MFA Official)** ใกล้เคียง mfa.go.th ที่สุด
  - `design-2-editorial.html` — **Modern Editorial** สะอาด เน้นเนื้อหา Bento grid
  - `design-3-learning.html` — **Learning Space** อบอุ่น เป็นมิตรกับนักเรียน/ครู/ชุมชน
  - `design-4-immersive-light.html` — **Immersive (โทนขาว)** (โมเดิร์น) hero รูปเต็มจอจางสู่พื้นขาว glass cards
  - `design-4-immersive.html` — **Immersive (โทนเข้ม)** โครงสร้างเดียวกัน โทนน้ำเงินเข้มทั้งหน้า
  - `design-5-swiss.html` — **Minimal Swiss** (โมเดิร์น) ขาวสะอาด กริดเส้นบาง ตัวอักษรใหญ่
  - `design-6-bento.html` — **Bento App** (โมเดิร์น) ทุกเนื้อหาเป็นไทล์แบบแอป + ช่องค้นหาใหญ่
- ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ Kanit / Sarabun จาก Google Fonts

## เนื้อหาในแบบ
ข่าว บทความ เกร็ดน่ารู้ และรูปภาพทั้งหมดดึงมาจากเว็บเดิม (aseanlibrarythailand.org) เพื่อให้ลูกค้าเห็นภาพจริง
ตัวเลขจังหวัดใช้ 77 จังหวัด (ภาคเหนือ 17 / อีสาน 20 / กลาง-ตะวันออก 26 / ใต้ 14) ส่วนจำนวนห้องสมุด 77 แห่งอิงข่าวล่าสุด และจำนวนภาพเป็นค่าตัวอย่าง ต้องยืนยันกับลูกค้า

## Section ที่แต่ละแบบมี → map ไปยัง Next.js/DB
- Hero / Slider → ตาราง `banners`
- ข่าวพิธีเปิด / ข่าวสาร → `posts` (type=news, category=opening|activity)
- บทความ 6 หมวด → `posts` (type=article, category=…)
- เกร็ดน่ารู้ / ศัพท์อาเซียน → `posts` (type=tip) หรือ `glossary`
- เครือข่ายห้องสมุด 77 แห่ง → `libraries` (school, province, region, lat/lng, opened_at)
- คลังภาพ → `media` + `albums`
